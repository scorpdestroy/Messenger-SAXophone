# Тесты сервера

Из корня проекта, в активированном виртуальном окружении Python 3.12+:

```sh
cd backend
python -m pip install -r requirements.txt
python -m pytest -q
```

Для запуска только проверок авторизации используйте
`python -m pytest -q tests/test_auth.py` из каталога `backend`.
Тесты авторизации используют отдельную SQLite в памяти для каждого сценария.
Для этого набора не нужны запущенный PostgreSQL и секретный ключ приложения.
Тестовый ключ и пароли генерируются при запуске.
